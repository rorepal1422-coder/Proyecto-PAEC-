    <h2>Soluciones para Disminuir la Violencia</h2><div class="caja">
  <p>
    Reducir la violencia requiere trabajo en equipo entre familias, escuelas y
    comunidades. Algunas acciones importantes son fomentar la empatía, resolver
    conflictos mediante el diálogo y promover valores como el respeto y la tolerancia.
  </p>

  <ul>
    <li>Promover la comunicación pacífica.</li>
    <li>Escuchar y respetar opiniones.</li>
    <li>Denunciar actos de violencia.</li>
    <li>Fomentar actividades deportivas y culturales.</li>
    <li>Crear campañas de concientización.</li>
    <li>Fortalecer la educación en valores.</li>
  </ul>
</div>
